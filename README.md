# Glass Optimizer Pro 🪟✨

A powerful tool designed for calculating and optimizing 2D **Float Glass** sheet cutting layouts to minimize material waste and maximize workshop efficiency.

## 🔍 What is Float Glass?
**Float glass** is the standard, high-quality flat glass sheet used worldwide for windows, doors, shopfronts, mirrors, and architectural structures. Because it is manufactured in large master sheets, cutting it precisely into smaller custom sizes for daily customer orders is a crucial requirement for every glass business.

## 🎯 Real-World Problem & Use Case
* **Small & Medium Glass Shops:** In everyday local glass shops and retail stores, workers calculate cutting layouts manually on paper or by guesswork. This leads to massive **Float Glass** wastage, human error, and heavy financial losses over time.
* **Workshops & Fabrication:** This tool runs smart optimization algorithms to determine the most efficient cutting pattern, drastically reducing material waste, saving raw material costs, and cutting down processing time for shops of all sizes.

## 💡 Why This Project Stands Out (Key Advantages)
* **Solves a Real Daily Pain Point:** Directly targets an expensive, everyday industrial problem faced by thousands of small businesses and fabricators.
* **Cost Effective:** Saves raw material expenses by maximizing the usage of every single sheet and reducing scrap pieces.
* **Zero Learning Curve:** Built with an intuitive, clean interface so that even a regular workshop worker or shopkeeper can use it effortlessly without technical training.

## 🚀 Key Features

* **Smart 2D Cutting Optimization:** Automatically calculates the exact layout configuration on the master sheet so the shop owner knows precisely how to cut.
* **Printable Mistri Instructions (PDF Report):** Owners can enter customer sizes, print the visual cutting layout sheet directly, and hand it over to the workshop worker (**Mistri**) for error-free cutting.
* **Off-Cut & Scrap Tracking:** Keeps a complete record of leftover usable glass pieces (off-cuts) from master sheets so they can be reused in future orders, ensuring zero wastage and complete business tracking for the owner.
* **Clean & Intuitive UI:** Designed keeping everyday shop operators and fabricators in mind.

## 🛠️ Tech Stack

* **Technology:** HTML, JavaScript

## 📦 How to Use / Run

1. Download or clone the project files from this repository.
2. Open the `index.html` file in any modern web browser.
3. Input your **Float Glass** master sheet dimensions and customer cutting requirements to get the visual layout instantly and print the report for the workshop!
