# Glass Optimizer Pro 🪟✨

> **Smart 2D Glass Cutting Optimization for Glass Shops & Fabrication Workshops**

Glass Optimizer Pro is a practical web-based tool designed to help glass businesses plan customer cuts against available stock sheets, optimize sheet usage, identify waste and reusable off-cuts, and generate professional production reports.

The project is designed around real-world glass fabrication workflows where accurate cutting plans, stock visibility, waste control, and clear workshop instructions are important for daily production.

## 🎯 The Real-World Problem

Glass shops and fabrication workshops regularly work with:

- Multiple stock sheet sizes
- Different customer cut requirements
- Large quantities of repeated sizes
- Manual cutting calculations
- Leftover off-cuts
- Material wastage
- The need for clear cutting instructions for workshop workers

When these calculations are handled manually, it can become difficult to select suitable stock, organize cutting patterns, track remaining pieces, and understand the actual material waste.

**Glass Optimizer Pro brings these tasks into one structured digital workflow.**

---

## 💡 What Is Glass Optimizer Pro?

Glass Optimizer Pro is a web-based glass cutting optimization tool designed for practical glass shop and fabrication workflows.

The application allows users to:

1. Import or enter stock sheet information
2. Add customer cutting requirements
3. Calculate an optimized cutting plan
4. Review stock sheet usage
5. Generate visual cutting patterns
6. Identify waste and reusable off-cuts
7. Generate a professional production report
8. Prepare job/payment estimation information

### Core Workflow

**Stock → Customer Demand → Optimization → Cutting Patterns → Waste / Off-Cuts → Production Report**

# 🚀 Key Features

## 1. 📊 Excel File Import

The application provides Excel file import functionality for practical workshop data entry.

Supported formats:

- `.XLSX`
- `.XLS`

This helps reduce repetitive manual entry when working with existing stock or order information.

---

## 2. 📦 Available Stock Sheet Management

Users can add and manage available master glass sheets.

Each stock entry can include:

- X Dimension
- Y Dimension
- Quantity
- Multiple stock sheet sizes

The optimization result shows which stock sheets are used and which sheets remain available.

---

## 3. ✂️ Required Cut Size Management

Customer cutting requirements can be entered with:

- Width
- Height
- Quantity
- Grid information
- Rotation option

Multiple required cut sizes can be processed together as one optimization job.

---

## 4. 🧠 Smart 2D Cutting Optimization

Glass Optimizer Pro calculates cutting plans using available stock sheets and required customer pieces.

The optimization output includes:

- Number of pieces
- Number of positions
- Total area
- Used piece area
- Used sheets
- Used sheet area
- Sold / required piece area
- Real waste
- Total waste
- Reusable waste
- Final waste

The objective is to organize the required pieces efficiently within the available master sheets.

---

## 5. 📐 Visual Cutting Patterns

The generated production report provides visual cutting patterns for individual master sheets.

Each cutting pattern can display:

- Master sheet dimensions
- Customer cut pieces
- Piece quantities
- Finished sizes
- Orientation
- Waste areas
- Remaining off-cut sizes

This makes the output practical for workshop production and cutting instructions.

---

## 6. ♻️ Off-Cut / Scrap Identification

The application identifies remaining areas after cutting and provides information about leftover pieces.

The report can show:

- Off-cut block ID
- Off-cut width
- Off-cut height
- Off-cut area
- Number of off-cuts

This helps the workshop identify leftover pieces that may be tracked for reuse.

# ▶️ How to Run

## Option 1 — Live Demo

Open the hosted live demo in a modern web browser and use the application directly.

## Option 2 — Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html`.
4. Open it in a modern web browser.
5. Enter or import available stock sheets.
6. Enter the required customer cut sizes.
7. Run the optimization.
8. Review stock usage, cutting patterns, waste and off-cuts.
9. Generate or print the production report.
